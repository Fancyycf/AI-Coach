# AI PM Coach

给想转 AI 产品经理的人做能力短板诊断的网页应用（当前为两页原型：落地页 + 测评介绍页）。

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

答题页使用简化版 CAT 引擎（[src/services/cat-engine.ts](src/services/cat-engine.ts)）：
每个维度初始难度 3，按「未测满 3 题的维度」轮询抽题，答对难度 +1（封顶 5）、答错 -1（封底 1）；
能力分按「新分 = 旧分 × 0.7 + 本题贡献 × 0.3」逐题更新，初始分 50。抽题与计分过程输出到浏览器控制台（`[CAT]` 前缀）。

结果页的「弱点诊断」由大模型生成（[src/services/diagnosis.ts](src/services/diagnosis.ts)）：
进入结果页只自动生成「答题数据足够（≥3 题）且分数最低」的维度，其余维度点「展开查看诊断」时按需生成；
调用失败按 1 秒、3 秒重试两次，仍失败则用内置的 6 维度 × 4 分数段共 24 段降级文本（卡片标注「（基础诊断）」）。
未配置密钥时 AI 调用必然失败，会稳定走降级文本，不影响功能演示。

每个薄弱点下方有「查看推荐资源」：AI 只生成资源标题、平台、类型、时长、理由和 3-6 个搜索关键词，
**绝不输出 URL**（解析器会直接拒绝任何含链接的输出），用户点击「用这个关键词搜索 →」跳转 Google 搜索自行验证。

### 复测对比

每次完成测评（≥10 题）会保存一个能力快照到 localStorage（`ai-pm-coach-snapshots`）：日期、六维得分、总分、答题数与答对数。
主页按快照数量展示：1 个快照显示当前雷达和复测引导；2 个及以上显示叠加对比雷达（本次主色实线 + 半透明填充，上次灰色虚线）与
总分变化、提升最大维度、仍需加强维度；3 个及以上提供完整成长曲线（时间轴 + 六维折线图）。
复测时 CAT 优先抽取用户从未答过的题（`createCatEngine` 的 `avoidIds` 参数），未答过题库不足时再回退旧题。
结果页根据与上次的对比显示反馈：总分 +10 以上庆祝、单维度 +15 以上庆祝该维度、总分下降给建设性话术并附「查看本次错题」、
持平给稳定建议。「立即复测」按钮按距上次测评天数（<3 天弱化 / 3-14 天正常 / >14 天高亮）提示。

### 配置 LLM（可选）

复制 `.env.example` 为 `.env` 并填写：

```bash
VITE_LLM_BASE_URL=https://api.openai.com/v1
VITE_LLM_API_KEY=sk-xxx
VITE_LLM_MODEL=gpt-4o-mini
```

前端直连 LLM 需要服务端允许浏览器跨域（CORS）；如果供应商不支持，需要加一个极小的代理层转发 `/chat/completions`。

> 说明：`esbuild` 以 `esbuild-wasm` 别名安装（本项目运行环境无法枚举用户目录，原生 esbuild 会报 "Cannot read directory"）。功能等价，仅构建稍慢；如需换回原生版，把 package.json 里的依赖改为 `"esbuild": "^0.25.12"` 后重装即可。
