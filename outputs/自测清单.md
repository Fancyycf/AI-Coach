> 版本：2026-08-12 加固后。开发服务器 http://localhost:5173（预览构建 http://localhost:4173）。
> 说明：情景题输入（超长/过短/重复提交）与评分页（评分依据/申诉）当前产品尚未具备，标记为 N/A，等对应功能上线后按预留方法补测。

## 第一组：核心 edge case

| # | 边界条件 | 测试方法 | 预期结果 |
|---|---|---|---|
| 1.1 | LLM 调用失败自动重试 + 降级 | 断网、填错误密钥，或浏览器 DevTools → Network 里把 `/chat/completions` 请求拦截为 500（重复 3 次） | 控制台出现 `[DIAG] 第 1/2/3 次调用失败`；诊断卡显示「（基础诊断）」+ 通用文本；不出现空白页/错误页 |
| 1.1b | 资源推荐失败 | 同上，点「查看推荐资源」 | 1s、3s 各重试一次后显示「资源推荐生成失败，请稍后重试 + 重试」 |
| 1.2 | 题库为空/维度题数不足 | 临时把 `src/questions.js` 的 `QUESTIONS` 改为空数组（或删光某个维度的题），刷新后进测评 | 答题页显示「题库未就绪，请联系管理员」，无法答题；改回后恢复正常 |
| 1.3 | 中途关闭浏览器 | 答 3 题后直接刷新页面（模拟关闭重开） | 主页出现卡片「你有一次未完成的测评，继续作答？」；「继续」从第 4 题接着答且已答记录保留；「放弃重来」从第 1 题重开并清除旧进度 |
| 1.4 | 雷达图无数据 | 清空 localStorage 的 `ai-pm-coach-snapshots` 后构造无分数数据（或直接改代码让雷达图收到空 dims） | 显示空状态「完成测评后查看你的能力雷达图」+「开始测评」按钮，不显示空白图形 |
| 1.5 | 情景题超长输入 | （N/A，当前为纯选择题）预留：输入超过 2000 字 | 强制截断并提示「请控制在 2000 字以内」；接近 1800 字时显示「还可以写 X 字」 |
| 1.6 | 情景题极短/空白 | （N/A）预留：输入少于 20 字点提交 | 提示「回答太短，请详细描述你的想法」，不可提交 |
| 1.7 | 快速重复点击提交 | 在答题页快速连点「下一题」（当前 MCQ 的提交动作）；预留情景题「提交」按钮 | 每次点击只前进一题（防重复锁）；预留：点击后按钮变为「提交中...」且不可再点 |
| 1.8 | 维度只答 1-2 题 | 用 localStorage 构造一个只答 2 题的会话（或临时把总题数调小） | 该维度诊断卡显示「答题数据不足，无法生成针对性诊断」，不调用 AI |

## 已实现但建议回归的既有功能

- 复测对比：完成两轮测评后主页出现「最近两次测评」总览与「查看两次测评对比雷达」；对比页可「返回测评结果 / 返回主页」；≥3 次出现成长曲线。
- 弱项诊断 + 学习资源：最弱维度自动生成、其余展开生成；资源只给搜索关键词、不输出 URL。
- 答题记录持久化：`ai-pm-coach-attempts` / `ai-pm-coach-snapshots`，刷新不丢失。
